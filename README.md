# KreoVolt Studio, сайт

Сайт студии разработки, дизайна и digital-маркетинга. Статический, без сборки: HTML, один CSS, один JS, шрифты и GSAP лежат в репозитории.

Живая версия: https://kidw3st.github.io/krevoltstudio/

## Структура

```
index.html            главная
services/index.html   услуги (10 позиций, якоря #sites ... #support)
work/index.html       работы (три демо-заглушки кейсов)
about/index.html      о студии
contact/index.html    контакты и форма заявки
privacy/index.html    политика конфиденциальности (черновик, заполнить реквизиты)
terms/index.html      пользовательское соглашение (черновик, заполнить реквизиты)
404.html              страница «лист не найден»
assets/css/site.css   все стили
assets/js/site.js     поведение и настройки контактов и формы
assets/js/vendor/     GSAP 3.13 и ScrollTrigger
assets/fonts/         Sofia Sans Extra Condensed и Golos Text (woff2)
assets/img/           favicon и место для картинок
docs/prompts-codex.txt промпты для генерации логотипа и картинок
docs/superpowers/specs дизайн-спецификация
robots.txt, sitemap.xml, llms.txt
.github/workflows/pages.yml деплой на GitHub Pages
```

## Что заполнить перед показом клиентам

1. Контакты и форма: откройте `assets/js/site.js`, объект `SITE` в начале файла. Заполните `telegram`, `max`, `email`, `phone`. Незаполненные контакты на сайте не показываются.
2. Приём заявок: сайт статический, без бэкенда. Укажите `formEndpoint` (например, адрес формы Formspree или своего обработчика, который принимает POST с полями `name`, `contact`, `message`, `consent`). Если endpoint пуст, но заполнен `email`, форма откроет почтовую программу с готовым письмом.
3. Реквизиты в документах: в `privacy/index.html` и `terms/index.html` замените текст в квадратных скобках на данные оператора. Тексты являются шаблоном, их стоит показать юристу.
4. Картинки и логотип: все заглушки помечены кодами A00, A01, A02 и так далее. Промпты и инструкция по подключению в `docs/prompts-codex.txt`.
5. OG-картинка `assets/img/og.png` (A01) пока отсутствует, meta-теги уже на неё ссылаются.

## Как редактировать

Шапка, футер и штамп повторяются в каждом файле страницы. Меняете ссылку в меню, значит меняете её во всех восьми файлах. Внутренние страницы используют пути с `../`, главная с `./`, страница 404 с `/krevoltstudio/`.

Правила из брифа, которые сайт соблюдает и которые стоит сохранять: без длинных тире в текстах, без эмодзи, без выдуманных отзывов, цифр и клиентов, без скруглений, теней и градиентов, без hover-анимаций. Один призыв к действию на всём сайте: «Обсудить проект».

## Локальный запуск

Любой статический сервер из корня репозитория, например:

```bash
python -m http.server 4173
```

или

```bash
npx serve .
```

Открывать по адресу `http://localhost:4173/`. Открытие файлов напрямую (file://) ломает переходы в подпапки.

## Деплой

При пуше в ветку `main` workflow `.github/workflows/pages.yml` публикует сайт на GitHub Pages. Если Pages ещё не включён и workflow не смог включить его сам, зайдите в Settings, Pages, Source: GitHub Actions и перезапустите workflow.

Внешних сетевых зависимостей у сайта нет: шрифты и GSAP лежат в репозитории.

## Лицензия

# KreoVolt Studio: дизайн-спецификация сайта

Дата: 2026-09-10. Статус: принято автономно по брифу владельца (интервью не проводилось, пользователь недоступен в ходе сессии). Все выведенные факты помечены.

## 1. Что строим

Многостраничный статический сайт студии KreoVolt (разработка, дизайн, digital-маркетинг в одной команде). Хостинг: GitHub Pages, репозиторий `kidw3st/krevoltstudio`, адрес `https://kidw3st.github.io/krevoltstudio/`. Без сборки: HTML, один CSS, один JS, self-hosted шрифты, GSAP self-hosted.

Одно целевое действие на всём сайте: «Обсудить проект» (форма заявки или мессенджер).

## 2. Архитектура (site-architecture)

```
Главная (/)
├── Услуги (/services/)            якоря: #sites #shops #web-services #bots #mvp #automation #design #ads #seo #support
├── Работы (/work/)                3 демо-заглушки кейсов
├── О студии (/about/)
├── Контакты (/contact/)           форма + контакты из конфига
├── Политика конфиденциальности (/privacy/)
├── Пользовательское соглашение (/terms/)
└── 404 (/404.html)
```

Хедер: логотип, Услуги, Работы, О студии, Контакты, кнопка «Обсудить проект». Футер: навигация, правовые ссылки, копирайт. Относительные пути (сайт живёт в подпапке).

Служебные файлы: `robots.txt` (AI-боты разрешены), `sitemap.xml`, `llms.txt`, `.nojekyll`, JSON-LD (Organization, WebSite, FAQPage, Service, BreadcrumbList).

## 3. Дизайн-направление (impeccable, бросок f7ccfa20, индекс 3)

Список моих grounded-кандидатов по резонансу: 1 электрощит и схема; 2 смета; **3 инженерный чертёж по ГОСТ (ЕСКД)**; 4 конструктивистский плакат; 5 проектный трекер; 6 Telegram-чат; 7 стройплощадка. Бросок назначил кандидата 3. Электрическая схема (кандидат 1) входит в мир чертежа как содержание листа (схема Э3), поэтому направление одно.

Вердикты по челленджерам каталога: керамическая полка (declined; донор: рядом с каждой позицией видно, что заказчик получает), сад дождя (declined; донор: на телефоне один доминирующий порядок чтения), эбру (declined; донор: процесс как одна непрерывная линия через страницу), монтажный стол (declined; донор: состояние показано меткой, а не цветом), кассетная дека (competitive по ясности; донор: у каждой услуги свой позиционный номер), швейцарская сетка (competitive по ясности; донор: одна модульная сетка на всех страницах, размеры шагами).

### Контракт

THESIS: сайт студии как комплект чертежей продукта заказчика. Лист с рамкой и основной надписью, спецификация вместо карточек, схема вместо иконок. Отказ от категории по умолчанию: тёмный лендинг с градиентами и тремя карточками.

OWN-WORLD: светло-серый чертёжный лист `#E6E7E2`, чернила `#151617`, один цвет «под напряжением» `#F2B700` (жёлтый маркер проверенных цепей), волосяные линии 1px, штриховка 45° как состояние загрузки, нулевые скругления, без теней. Шрифты: Sofia Sans Extra Condensed (заголовки, ярлыки, цифры, капс) и Golos Text (текст). Контролы: прямоугольники с рамкой 1px, мгновенная смена состояния без анимации.

STORY: посетитель понимает за секунды, что студия делает всё от идеи до поддержки, видит состав работ как спецификацию, порядок работ как одну цепь, и оставляет заявку.

FIRST VIEWPORT: слева заголовок в 3 строки экстра-узким капсом с жёлтой маркерной подсветкой ключевых слов, подзаголовок 17 слов, две кнопки (жёлтая «Обсудить проект», контурная «Состав работ»). Справа схема Э3: вертикальная цепь от источника «Идея» через пять контактов (Прототип, Дизайн, Разработка, Запуск, Продвижение) к лампе «Клиенты»; при загрузке цепь последовательно замыкается и загорается жёлтым. Весь экран внутри чертёжной рамки; основная надпись (штамп) закреплена справа внизу на десктопе и содержит CTA.

FORM: инженерный чертёж по ГОСТ, позиция 3 в моём списке, seed key f7ccfa20. Режим Persuade.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.

### Раскладки секций главной (по одной семье на секцию)

1. Hero: split 7/5, заголовок + схема.
2. Состав работ: спецификация (таблица позиций) в 4 группах, липкий заголовок группы слева.
3. Порядок работ: горизонтальный рельс с 5 станциями, жёлтое заполнение по скроллу (scrub), на мобильном вертикальный.
4. Работы: горизонтальная лента с scroll-snap, 3 заглушки кейсов.
5. Полоса утверждения: жёлтое поле с крупной фразой.
6. Вопросы: details/summary с линейками.
7. Контакт: форма 7/5 + контакты.
Футер: чернильный, крупный вордмарк жёлтым, навигация, правовые ссылки.

### Ограничения брифа (обязательные)

Нет: резких градиентов, Lucide, чисто белого фона, радуги, drop shadows, трёх карточек в ряд, эмодзи, liquid glass, длинных тире, Inter/Geist/Space Grotesk, цветной левой полосы, выдуманных отзывов, bento, окна терминала, галочек, трёх тарифов, скруглений, фиолетового с чёрным, orbs, точечных сеток, искр, анимированных стрелок, hover-анимаций, неона, пастели.
Есть: политика конфиденциальности, пользовательское соглашение, состояние загрузки изображений, места под реальные демо (заглушки с ID и промптами).

## 4. Движение (animate, gsap-scrolltrigger, staggered-word-reveal)

- Hero: заголовок появляется по словам (CSS, один раз); схема «запитывается» таймлайном GSAP при загрузке.
- Порядок работ: заполнение рельса привязано к скроллу (scrub), станции получают метку «под напряжением».
- Позиции спецификации и кейсы: одиночное появление по батчу.
- Hover: мгновенная инверсия цвета (без transition). `prefers-reduced-motion`: всё статично, схема замкнута.
- Без GSAP (нет сети): всё видно в конечном состоянии.

## 5. Контент и заглушки

Тексты на русском, без длинных тире и восклицаний. Никаких выдуманных цифр, клиентов, отзывов, цен. Контакты и endpoint формы задаются в `assets/js/site.js` (объект `SITE`), незаполненные скрываются.

Заглушки изображений имеют ID (A01, A02, ...) и описание внутри блока. Промпты для генерации в `docs/prompts-codex.txt`.

## 6. План реализации

1. `assets/css/site.css`, `assets/js/site.js`, шрифты, GSAP self-hosted.
2. `index.html` со всеми секциями и JSON-LD.
3. Подстраницы: services, work, about, contact, privacy, terms, 404.
4. Служебные файлы: robots, sitemap, llms.txt, .nojekyll, README, workflow Pages.
5. Проверка в браузере (desktop, mobile), детектор impeccable, аудит на слоп, правки.
6. Промпты для Codex (txt), коммит, пуш, деплой Pages, проверка живого URL.

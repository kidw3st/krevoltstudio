KREOVOLT STUDIO. ПРОМПТЫ ДЛЯ ГЕНЕРАЦИИ АССЕТОВ (Codex / генерация изображений)
Версия 1, 10.09.2026

Как пользоваться
1. Каждый ассет имеет код (A00, A01, ...). Такой же код стоит внутри заглушки на сайте.
2. Скопируйте блок PROMPT целиком в Codex. Строку STYLE BASE вставляйте в начало каждого промпта.
3. Сохраните результат под именем из строки FILE в папку assets/img/ репозитория.
4. Подключение: внутри заглушки <figure class="ph" data-asset="Axx"> в блок <div class="ph__box"> добавьте
   <img class="ph__img" src="../assets/img/ИМЯ_ФАЙЛА" alt="ОПИСАНИЕ" loading="lazy" width="W" height="H">
   (на главной странице путь начинается с ./assets/, на внутренних с ../assets/).
   Штриховка и подпись заглушки скроются автоматически после загрузки картинки.
5. Логотип (A00) подключается отдельно, см. раздел A00.

A00. ЛОГОТИП (знак + вордмарк)
==========================================================================
Где используется: шапка сайта, штамп (основная надпись), футер, favicon, OG-картинка, документы.
Сейчас на сайте: временный знак (жёлтый квадрат с чёрной рамкой) и вордмарк «KREOVOLT», набранный шрифтом Sofia Sans Extra Condensed 800.

Концепция
Знак: «замкнутый контакт» из электрической схемы, вписанный в букву K.
- Вертикальный штрих буквы K = шина (линия питания).
- Две диагонали буквы K = подвижный контакт выключателя, который повернулся и замкнул цепь.
- В точке, где диагонали сходятся с вертикалью, стоит узел: круг, залитый жёлтым #F2B700 с чёрной обводкой. Узел означает «под напряжением»: студия включает продукт.
- Всё строится из линий одной толщины (как чертёж), без засечек, без наклона.
Вордмарк: «KREOVOLT» прописными, очень узкий тяжёлый гротеск (образец: Sofia Sans Extra Condensed 800), трекинг слегка положительный, «STUDIO» мелко под вордмарком или справа, с широкой разрядкой.
Варианты: 1) знак отдельно; 2) вордмарк отдельно; 3) горизонтальный лок-ап (знак слева, вордмарк справа); 4) вертикальный лок-ап; 5) монохром чёрный; 6) инверсия на чёрном #151617 (линии светлые #E6E7E2, узел жёлтый); 7) на жёлтом поле #F2B700 (линии чёрные, узел чёрный с белым кольцом).

FILE: logo-mark.svg, logo-wordmark.svg, logo-horizontal.svg, logo-vertical.svg (+ PNG 2000 px по длинной стороне для каждого варианта)
SIZE: векторный, квадратная сетка 64x64 единиц для знака

PROMPT (для генерации картинки-референса знака):
[STYLE BASE] Logo mark design, flat vector style, centered on a plain #E6E7E2 background. A monogram letter "K" constructed from schematic circuit strokes of uniform stroke weight: the vertical stem of the K is a straight bus line; the two diagonal strokes of the K are a single pivoting switch contact that has rotated to close the circuit; at the junction point of the stem and the diagonals sits a circular node filled with signal yellow #F2B700 and outlined in ink #151617. Geometric, monoline, sharp square line ends, no rounded corners, no serifs, no italics, no lightning bolt, no spark, no 3D, no gradient, no glow, no shadow, no background texture, no extra text. The mark should read clearly at 16 px favicon size and at 2 m signage size. Present 6 small variations in a grid on one sheet, each variation labeled only with a tiny number.

PROMPT (для векторной сборки в Codex, если Codex пишет SVG):
Create an SVG logo mark on a 64x64 viewBox for "KreoVolt": a letter K built from monoline circuit strokes (stroke #151617, stroke-width 6, square linecaps), vertical stem from (20,8) to (20,56); the K diagonals are one rotated switch contact: upper diagonal from the junction (20,32) to (46,10), lower diagonal from (20,32) to (46,54); a node circle at (20,32) r=7 fill #F2B700 stroke #151617 stroke-width 3. Also produce a wordmark SVG "KREOVOLT" in an extra-condensed heavy grotesk converted to outlines (font: Sofia Sans Extra Condensed weight 800, letter-spacing 0.02em, uppercase, color #151617) and a horizontal lockup where the mark height equals the cap height of the wordmark with a gap of 0.35 cap heights. Export additional variants: monochrome black, inverted on #151617 background (strokes #E6E7E2, node #F2B700), and on #F2B700 background (strokes #151617, node #151617 with a 2px #E6E7E2 ring). Keep all corners sharp.

NEGATIVE: lightning bolt, spark, plug icon, gradient, glow, neon, rounded corners, purple, blue, 3D bevel, shadow, hand-lettering, script font.

Подключение на сайте: заменить блок <a class="brand" ...>KreoVolt</a> в шапке каждой страницы на <a class="brand" href="./"><img src="./assets/img/logo-horizontal.svg" alt="KreoVolt Studio" height="28"></a> (на внутренних страницах пути с ../). Favicon: заменить assets/img/favicon.svg на logo-mark.svg (сохранить имя favicon.svg).

ФОРМАТЫ И КОНТРОЛЬ КАЧЕСТВА
==========================================================================
- Рендеры (A02-A05): PNG, sRGB, без прозрачности, фон #E6E7E2 сплошной, чтобы картинка сливалась с листом сайта.
- Фотографии (A06-A10): JPG качество 85, sRGB.
- Логотип (A00): SVG с обведёнными контурами (текст в кривых), плюс PNG.
- Перед публикацией сжать: PNG через oxipng или squoosh, JPG через squoosh. Целевой размер файла: до 400 КБ для широких картинок.
- Проверить на сайте: заглушка исчезает, картинка не растянута (object-fit: cover), alt-текст заполнен.
